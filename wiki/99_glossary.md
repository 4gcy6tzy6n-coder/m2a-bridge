# 术语表

## 机制与假设

- **H-F（通用反馈控制）**：不需要机制特异生物回路，观测历史 + action history + 容量 / 可观测性 / 时延决定控制。
- **H-D（竞争性去抑制 / 运动 opponency）**：对称平移与差分旋转通过竞争或抑制分离；不要求行动拷贝。
- **H-P（动作条件预测 / 感觉反馈误差）**：内部状态与过去动作产生自运动感觉预测，残差驱动行动。
- **reafference**：生物体自身运动造成的感觉输入。
- **efference copy**：动作指令的内部副本，用于预测自运动感觉后果；只有观察到运动相关活动时不能当作已证实机制。
- **Motion-to-Action**：从运动 / 感觉流到行动的计算问题；本项目的核心问题域。

## 门禁与证据

- **G0–G5**：数据、新颖性、预测、人工、联合、科学 / 投稿六道硬门，见 [21 门禁与统计](21_gates_and_stats.md)。
- **B0–B3**：生物验证等级，B0 文献重述、B1 公开数据 held-out、B2 新动物 / 新 session 盲法、B3 新动物随机干预 + 行为 / 神经联测。
- **T1–T5**：Route A 的五段推断链：结构→计算、计算→对应、对应→效用、效用→普适、任何→宣称范围。
- **E0–E4**：证据等级：E0 论文内无证据 / 仅引用；E1 暗示性；E2 论文内受控；E3 外部独立证据；E4 外部复现或对抗评估。
- **co-primary**：两个共同主要终点；两个域都必须过各自预注册门，才可谈联合结论。
- **TOST**：two one-sided tests，用于在预设等效界限内论证“无实质差异”，不能只用 `p > 0.05`。
- **prequential / held-out log likelihood**：用预测序列或留出数据的似然比较竞争模型，避免只看拟合优度。
- **ICC**：组内相关系数，用于估计动物间方差，做功效分析。

## 数据与工程

- **flyvis**：连接组约束的果蝇视觉模型与刺激 / 神经响应工具（Lappalainen et al. 2024）。
- **FlyGym / NeuroMechFly v2**：果蝇具身仿真平台；2.x 是重写 API，与 1.x 不兼容。
- **BANC**：2026 年脑-神经索完整连接组资源。
- **LC15**：Dryad 数据中与本项目转向机制可能相关的细胞 / 读数标签；是否直接对应尚未核实。
- **round gate**：本工作区的实验前置门禁；没有通过的 debug 证据，实验不得启动。

## 项目

- **M2A（旧）**：Motion to Action 合成模型理论程序，已冻结；`FROZEN_HISTORICAL_EVIDENCE`。
- **Route A（旧，文献审计）**：T1–T5 文献证据审计，接近 NMI 投稿；`FROZEN_HISTORICAL_AUDIT`。
- **Route A（DRBA）**：M2A 理论轨里的算法设计，`REDUNDANT`；与文献审计不是同一项目。
- **M2A-BRIDGE**：本项目，双向机制发现；`PROPOSED_NOT_PREREGISTERED`。
