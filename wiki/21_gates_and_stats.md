# 门禁、证据等级与统计规则

> 本页是 M2A-BRIDGE 的“能不能说”的规则；数字阈值在 owner 冻结前都只是草案。

## 1 六道硬门

| 门 | 必须证实 | 未通过的动作 |
| --- | --- | --- |
| **G0 数据** | 真实生物刺激 / 神经 / 行为输入，独立干预或合作实验路径，合法可访问性 | 停 Nature 旗舰确认；仅计算 pilot |
| **G1 新颖性** | 相对 flyvis / FlyGym / Erginkaya / BANC / FlyHack / FlyGM 有预先书面列出的**非重合**新问题 | 重选具体机制或停止 |
| **G2 预测** | 在看目标生物结果前冻结多个竞争机制的不同预测，独立神经 / 行为数据可判别 | 停机制发现叙事；不挑成功案例 |
| **G3 人工** | 匹配最强通用对照和机制 null，独立任务迁移有可归因且重要的作用 | AI 转移不成立；保留生物机理稿或负结果 |
| **G4 联合** | 生物干预效应与 AI 干预预测形成可量化的跨系统一致性，并支持一个未见扰动 / 状态 | 不声称共同机制与完整 Nature 故事 |
| **G5 科学 / 投稿** | 独立人类复核、论文重合与数据许可、动物实验审批、可复现包、作者 / 审稿披露、真实新发现足够广泛 | 不标 `NATURE_READY`；按实际结果分流 |

**G0 的停止条件**：若没有独立生物干预或神经活动结局且无潜在合作方，暂停 Nature 主刊确认研究；保留计算 / 方法论文路线。**不能以模拟动物替代真实生物确认。**

## 2 生物验证等级

| 等级 | 内容 | 能支持什么 |
| --- | --- | --- |
| `B0` | 仅公开文献重述 | 背景，不是验证 |
| `B1` | 独立公开数据 held-out 预测 | 较弱验证；不自动升级 |
| `B2` | 新动物 / 新 session、盲法生理验证 | 独立验证 |
| `B3` | 新动物随机干预与行为 / 神经响应联测 | 强证据；Nature 强主张应争取 |

## 3 统计与独立单位

- **生物学**：动物是主要独立单位。细胞、帧、时间点不等于独立动物 n。跨天 / 批次用多层模型显式处理 animal、session、trial、batch。
- **连接组**：一个动物的 connectome 不能靠多个 cell class 变成多个独立个体；外推须审查动物与性别差异。
- **AI**：seeds 是训练随机性重复；任务族 / 环境 / 传感器变化才是外推单位。多个 clip 不是独立任务族。
- **跨系统**：成对扰动比较的单位是机制条件 / 回路；在 animal × AI seed × perturbation 的层级分析，不对两个系统的原始量纲做无效合并。

### 先导后功效

先做盲法开发 pilot，估计方差、动物间 ICC、可评估率和主变量方差；再用嵌套动物 bootstrap 或混合效应模拟，确定能检出**最小有意义效果**所需的独立动物数和可执行干预条件数。

**当前不得声称 12、20 或 30 只就一定有 80% 功效。** 动物数不够时缩小问题或止步，不以 trial 数填补。

### 确认性分析建议

- 生物主检验：层级混合效应模型估计 `intervention × feedback_condition`；动物级 cluster bootstrap CI；同时报告效应量、扰动效力、sham 检验。
- 竞争机制：prequential / held-out log likelihood 或 proper score；标准化模型复杂度、读数噪声、任务设置。
- AI 主检验：跨未见任务族的 paired performance difference；seed + environment 分层不确定性；预算匹配表。
- 联合检验：两个 co-primary 域均过各自预注册门，且 cross-system 挑战预测达到事前要求；任一失败不得用探索指标替代；多主要检验控制整体错误率。
- “无差异”不能只靠 `p > 0.05`；要声称通用控制足够，需要事前等效界限和 TOST / 区间论证。

### 缺失与失败分类

`NOT_OBSERVABLE` / `TECHNICAL_FAILURE` / `BIOLOGICAL_NULL` / `MECHANISM_CONTRADICTED` 分开记账；**不得把不可用数据按 0 填**。

### 确认与探索隔离

探索可以在新分支 / 新数据上发生，但关键提名必须绑定发布日期、sha256、随机种子、动物名单与解封时间。最终判决用完全新的动物、记录批次或预留刺激集。**看到最终结果后不准更换主终点、阈值、对照或机制定义。**

## 4 不可写的话

- 不得把“可下载”写成“同动物配对”。
- 不得把公开既有机制重述称为新发现。
- 不得因先导结果强行更换主机制。
- 不得把“两端都改善”写成“同一机制”。
- 不得把 B1 写成 B3。
- 不得用 trial 数冒充动物 n，用 episode 数冒充任务族 n。
- 不得把旧 M2A 的 S-only 或旧 Route A 的 58 条写成新实验的独立确认。
- 不得在 G0 未过时标 `NATURE_READY`。
