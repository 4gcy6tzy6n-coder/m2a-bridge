## 2. epoch 结构

- 两批次各 **3 个折叠 epoch：uniform / stationary / flicker**（前景条件）；
  分析用 epoch 1–2（uniform vs stationary）差值轨迹，逐时间点跨蝇 sign-rank。
- 无其他时序变化水平；每批次内等待时长恒定。

## 3. 对 D10 修正案三问的答复

| Owner 的问题 | 映射结论 |
| --- | --- |
| 是否有多个独立延迟水平？ | **有两个水平（666/500 ms），但为批次间设计**：延迟与动物批次（27 vs 17 只不同蝇）及运动时长（333 vs 500 ms）三重混淆——不存在同批可比的延迟剂量轴 |
| 操纵的是视觉起始时序还是反馈延迟？ | **纯视觉证据出现顺序**（前景静止先于背景运动）；无任何自身状态/闭环反馈延迟成分——与 owner 判断一致 |
| H0/H1 是否也能预测起始响应？ | 是：两个固定等待条件下的起始时间曲线可由视觉时间核/积分模型预测；在该设计上 H2 无独有方向性预测 |

## 4. 该数据集的可用性定位（P3-T）

- **可用**：视觉证据整合机制的探索性模型判别——各模型对留出动物的
  响应时间曲线、抑制起始时刻（uniform−stationary 差值过零/达峰时间）、
  两批次间曲线形状差异的预测比较。竞争模型集按 owner 扩充为：
  视觉时间核模型、泄漏积分器、状态空间模型（+H0/H1/H2）。
- **不可用**：任何"自身状态延迟的生物验证"；任何延迟剂量-反应检验。
- 原论文已报告的"预呈现使抑制提早出现（运动开始后 ~150 ms 显著）"
  属既有结果，只能作基准对照。
