## 1. 核心主张（待检验，非预设）

Track C 的配方（**新鲜状态快通路 + 受扰慢通路门控**）在通用延迟反馈
控制任务中同样必要：延迟观测下的估计器族与匹配预算经典控制器
不能替代新鲜状态反馈；门控预测失稳边界与扰动后的恢复。

## 2. 任务套件（容量与延迟可调）

| 任务 | 延迟维度 | 与飞行模型的对应 |
| --- | --- | --- |
| T1 延迟倒立摆（cart-pole variant） | 观测延迟 0–500 ms 连续扫 | 最小可复现单元 |
| T2 二阶自旋体姿态保持（Track C 植物的无视觉重述） | 视觉式延迟 + 已知动力学 | 直接同构 |
| T3 部分观测 LQR 基准（经典文献锚点） | 延迟 + 过程噪声 | 与 Smith/KF 文献对照 |

## 3. 控制器族（匹配信息与预算；对应稿件 R2 的生物模型对照）

- E 延迟估计器族：死推、卡尔曼/扩展卡尔曼、前向模型（Smith）——
  只看延迟观测（对齐 F&S/Taylor/smith 生物结论）。
- C 经典即时状态族：PD/LQR——同信息预算（对齐 pd_instant 结论）。
- **F 新鲜状态快通路 + 慢通路门控**（Track C 配方；消融：无门控/无快通路）。
- U 理想状态反馈上界。

## 4. 指标与判据（预注册草案）

- **失稳边界**：逐任务的临界延迟曲线（failure 定义按任务标准：倾角/位置
  越界或发散）；预测：E/C 族临界延迟短，F 配方显著更长，消融拆解各成分。
- **扰动恢复**：延迟阶跃 + 外推冲击下的恢复时间；预测：门控消融恢复变慢。
- **跨任务泛化**：同一配方排序在 T1–T3 一致（任务族为独立单位，非轨迹）。
- 统计：任务族级重复（参数随机化 ≥30 个/任务）；效应量 + 区间。
