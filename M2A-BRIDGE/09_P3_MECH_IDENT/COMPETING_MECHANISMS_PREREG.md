## 0. 总原则（owner 裁决原文级约束）

- 三者必须使用**明确限定的信息集**与**相称的模型容量**；比较 held-out 神经时间序列的
  预测性能与跨条件泛化；核心是"哪个机制产生其他机制无法预先解释、又被独立数据支持的预测"，
  不是哪个拟合最好。
- **H1 > H0 只证明可观测运动历史提供增量信息**；无额外干预时不得声称发现了
  efference copy 的具体神经来源。
- 独立单位=蝇；ROI/时间窗/试次不是独立动物；同一动物的片段不得跨越训练/最终检验边界。
- 无法识别时输出 `MECHANISM_NOT_IDENTIFIABLE`；不得用更复杂 ANN 替代缺失的观测/干预。

## 1. 三个假说（冻结定义）

### H0 · Visual-only
- **信息集**：仅视觉刺激历史（刺激帧/参数化刺激序列）。
- **实现**：线性-非线性（LN）或低容量核回归，核长 L 在训练动物内 CV 选定。
- **预测对象**：held-out 蝇的神经时间序列（成像 ΔF/F 或膜电位）及对应行为通道。

### H1 · Motor-history-conditioned
- **信息集**：H0 的视觉历史 **+ 可观测运动历史**（同一记录中的 L−R WSA / 球上转向速度，
  仅使用在预测时刻 t 之前可测的运动样本；无跨试次信息泄漏）。
- **实现**：与 H0 同族模型 + 运动历史支路；总参数量与 H0 匹配（容量对照：H0 加等参数的
  噪声支路作为 capacity control）。
- **含义边界**：运动历史增益 = 可观测运动信号的预测价值，≠ efference copy 来源。

### H2 · Latency-sensitive state estimation
- **信息集**：视觉历史 + **带显式延迟/可用性约束的自身状态估计**
  （M2A 计算框架的操作化：状态通道延迟 τ、采样新鲜度 δ、可用性开关）。
- **实现**：状态观测器结构固定，只拟合与 H0/H1 同量级的自由参数（增益类）。
- **硬规则**：若数据缺少区分该机制所需的状态观测（无同时运动通道，或无延迟/时序维度），
  该数据集上 H2 标记 **`MECHANISM_NOT_IDENTIFIABLE`**，不参与胜负判定。

## 2. 判据（冻结）

1. **主判据**：留出动物上的神经时间序列预测性能（解释方差 R²，
   按动物报告中位数与 bootstrap 95% CI）。模型选择动物与最终检验动物不重叠。
2. **判别条件要求**：至少一个**未用于模型选择**的实验条件上，两个机制给出
   **预先写明的、方向不同的预测**（见 §3 表）。没有这样的条件 → 该数据集不支持
   机制判别，只支持预测性能比较。
3. **决策规则**：仅当 (a) 一个机制在留出动物上显著优于另一机制（动物级配对置换，
   α=0.05，预注册单侧方向），且 (b) 至少一条预先写明的方向性判别预测被独立数据支持，
   才记 `MECHANISM_DISCRIMINATED_ON_<dataset>`；否则 `NOT_DISCRIMINATED`。

## 5. 与 Track C / M2A 计算框架的关系（边界）

## 修正案 A1（2026-10-28，owner D11——追加于任何 fig1_05 结局检验之前）

1. **撤回** §3 表中"Tanaka fig1_05 延迟起始"判别预测行。理由（owner 裁决 + T1
   时序映射）：该延迟为视觉证据出现顺序而非反馈传输延迟；666/500 ms 两水平与
   动物批次、运动时长三重混淆（`T1_TIMING_MAP_fig1_05.md`）；H0/H1 可经视觉时间
   积分预测起始响应，非 H2 独有。该行从未用于任何检验（无结局暴露），撤回合規。
2. **竞争模型集扩充**（owner D11）：除 H0/H1/H2 外，**视觉时间核模型、
   泄漏积分器、状态空间模型**必须进入竞争集合；判别要求对整个模型族成立，
   不得只比较三个机制标签。
3. **P3-F（F&S）成为优先判别线**；F2 分析的偏差防范升级为本预注册的一部分：
   (a) 禁止将与待预测神经活动同一时间点的行为响应作为输入（只能用 t 之前的运动
   历史）；(b) 禁止按测试试次膜电位符号挑选"易预测"HS 细胞组——细胞/试次选择
   只允许在开发数据上进行；(c) 数据切分按整动物。
4. 主张边界重申（owner D11）：即便 H1 类胜出，也只声称"额外预测信息"；
   Nature 级主张须达到"行为状态依赖的预测机制在特定时序/信息条件下必要，
   且必要性同时约束真实神经响应与人工控制失败边界"——当前为**待验证假说**。
