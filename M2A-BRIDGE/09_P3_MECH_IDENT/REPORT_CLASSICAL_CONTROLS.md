# 报告一：经典控制方法是否已经解释 Track C 的全部优势？

> D13 指定交付（2026-10-29）。证据：P2-OBSERVER-02（本轮）+ P1-EC-OBSERVER-01
>（Taylor，C37）+ P1-EC-DAMP-01（C35）+ P1-EC-FEEDFORWARD 对照（C19）。
> 全部为模型内结果；本报告不涉生物主张。

## 结论（一句话）

**没有。** 在 Track C 的模型与标准参数网格上，两条经典替代路线
（延迟信息的估计器；匹配预算的即时经典反馈）都未能复现
"即时自身状态 + 门控 goal 支路"在 50–200 ms 延迟下 0% 失败的优势；
但优势的**必要成分是新鲜自身状态进入快通路**，门控的独立贡献限于
模型内特定对照。

## 逐路线证据

| 替代解释 | 检验 | 结果 | 判定 |
| --- | --- | --- | --- |
| 平凡外推估计器（Taylor） | P1-EC-OBSERVER-01（C37） | 50 ms 起 50–100% 失败 | 不解释优势 |
| **完整前向模型观测器（Smith 类，延迟观测输入）** | **P2-OBSERVER-02**：精确参数与 10% 失配两版 | **≥100 ms 全失败（1.00），50 ms 0.50** | **不解释优势**（按本实现；限制见下） |
| 即时状态经典 PD（同 p/v 增益、同植物滤波、无门控） | P2-OBSERVER-02 | **38–62% 失败（全部延迟）** | **不解释优势**（匹配预算版本；未整定增益） |
| 即时状态、goal 支路、无门控（graded_goal ff=1） | 既有 C19 | 62–75% 失败 vs gate goal 0% | **门控在模型内有独立贡献** |
| 即时状态纯阻尼（无 goal、无门控特殊性） | 既有 C35 | 阻尼 ≥1e-11 即救回 gate | **必要成分 = 新鲜自身状态**（非 goal 内容、非门控本身） |

## 综合图景（模型内）

延迟下失稳的解药在本模型中是**把新鲜自身状态接入快速反馈路径**
（goal 支路或纯阻尼均可），并让受扰动的视觉运动通路在快通路工作时门控；
仅有延迟观测的估计器——无论 Taylor 外推还是前向模型——都不救；
匹配预算的经典 PD 也不救。**Track C 的优势主张收窄为**：
"新鲜自身状态 + 门控配方在本延迟模型中超越所测经典替代"——
不是"超越一切经典控制"。

## 限制（必须随报告引用）

1. pd_instant 未做增益整定（matched-budget 设计；更强的经典控制器未排除）。
2. Smith 观测器未嵌入延迟微分方程（朴素前向模型；DDE 感知观测器未测）。
3. 噪声 1e-13 在本网格无可见效应，稳健性不外推到更大扰动。
4. 全部为单模型内计算结果（8 参数组）；不构成生物机制证据。

## 对 D13 旗舰问题的意义

第一个判据问题的答案是"否，经典控制未解释全部优势"——但剩余优势的
结构（新鲜自身状态的必要性 + 门控的模型内独立贡献）恰是旗舰目标中
"动作相关状态信息何时构成计算必要信息"的**计算侧候选核心**。
生物侧能否独立验证该必要性，取决于报告二的数据线。
