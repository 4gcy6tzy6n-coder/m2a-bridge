## 2. Rayshubskiy et al.（Harvard Dataverse doi:10.7910/DVN/0NCLP1）——**`QUALIFIED`（神经+行为+干预三轴，2026-10-29）**

- Dataverse API 实测：380 文件、**157.89 GB**；行走转向神经回路
  （83blexA 系 csChrimson 干预 + GFP 对照 + 双区记录 + `bdata_*` 行为文件）。
- **行为样本核验（bdata，18 MB）**：10 kHz、60.5 s、14 通道
  （球传感原始 + 航向样 + TTL 标记），列语义待其 loader 代码（非阻塞——
  主分析走 SH 文件）。
- **神经样本核验（owner 下载，2026-10-29，两个文件尺寸与清单精确一致）**：
  - `161218_lexAOpCsChrimson_gfp_83blexA_ss731_02`（干预系）与
    `170802_gfp_ss731_03`（GFP 对照），同一 schema：
  - `ephys_A` 单通道膜电位 **4 kHz**（干预文件 −72…+105 mV，动作电位可见）；
    `fwd/lat/yaw` 球速度 **100 Hz**；`t_ephys`/`t_ball` 同一 session 同一起点
    （0→3000 s / 0→2875 s）——**双时钟对齐，逐时刻可配对**；
  - **`stim` 通道（与 ephys 同钟，0/5 V）：干预文件含 261 个光刺激时段**
    （522 次电平跳变，首个 3.0–3.5 s，~11.5 s 间隔）——**真实实验者干预轴**；
    GFP 对照文件 stim 全 0（自发行为对照）。
- **判别所需六轴全部就位**：神经 ✓ 行为 ✓ **干预 ✓** 刺激标记 ✓ 时间基准 ✓
  独立单位 ✓（每文件=一只蝇一次会话；全数据集约 23 个 SH 会话）。
- 定位（owner D13）：**跨行为形式（行走↔飞行）泛化候选**，不是 F&S 复制；
  干预轴使"行为状态依赖的扰动响应"这类 H2 向问题首次可检验（F&S 无干预）。
- 边界：83blexA 系身份与原文结论（DNa02 等转向下降神经元）以论文为准，
  不得再包装为我们的发现；行走结论不与飞行效应量合并。
- 剩余步骤：(a) 从原论文/代码确认 83blexA 靶神经元身份与 stim 编码；
  (b) 按 P3-F-LOCK 五约束起草跨系统判别预注册 → owner 审批 → 单次运行。
